# Mercury Continue (Codex)

Resume a Mercury initiative without context loss.

1. Read `PROGRESS.md`, `CONTEXT.md`, `PLAN.md`, `HANDOFF.md` in that order.
2. Verify drift: HEAD vs recorded, git status, FIXED greps.
3. If drift found, update `CONTEXT.md` and ask before continuing.
4. State next step and wait for `go`.

Command alias: `mercury-continue`.
