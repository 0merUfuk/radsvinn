# Radsvinn Doublecheck (Codex)

Run four adversarial passes before any human gate.

Passes:
1. Gap Finder.
2. Assumption Attacker.
3. Ground Truth Verifier.
4. Devil's Advocate.

Verdict bands:
- 95–100 SHIP
- 80–94 FIX FIRST
- <60 REDESIGN

Re-run only the failed pass after fixes.

Command alias: `radsvinn-doublecheck`.
