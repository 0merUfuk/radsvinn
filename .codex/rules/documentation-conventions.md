# Documentation Conventions (Codex)

1. Org-neutral language everywhere.
2. Load-bearing designs live in tracked `docs/` or `blueprints/`.
3. `docs/ARCHITECTURE.md` is the design-of-record.
4. Every ADR has status, date, and supersession clause.
5. `README.md` is the product front door.
6. Context files follow the session protocol.
