# Session Protocol (Codex)

Context files (`SERVICE_CONTEXT.md`, `NEXT_STEPS.md`, `KNOWN_ISSUES.md`, `DECISIONS.md`) are read on branches, written only on main via follow-up PR.

Session state goes to gitignored `tasks/{slug}/`.

This is the same rule as `.claude/rules/session-protocol.md`; both must be kept in sync.
