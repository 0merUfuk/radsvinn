# Mercury Source Context Template

Use when scaffolding a new Mercury module or service.

## What to capture

1. Module purpose in one sentence.
2. Public interface (HTTP routes, CLI commands, exported functions).
3. Dependencies on other modules.
4. Invariants from `CLAUDE.md` / rules that apply here.
5. Current status and next steps.
6. Known issues.

## Format

```markdown
# {module} — Source Context

## Purpose
...

## Interface
...

## Dependencies
...

## Invariants
...

## Status
...

## Next steps
...

## Known issues
...
```
